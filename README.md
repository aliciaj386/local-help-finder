# Local Help Finder

## Project Purpose
Local Help Finder is a web application created for a computer science course. It demonstrates how a website can organize assistance resources into four categories: Food, Utility bills, Housing, and Financial needs.

**Important:** All resource listings in this version are fictional examples for educational purposes. They are not real organizations and cannot provide assistance.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express

## Features
- Displays four assistance categories.
- Allows users to select a category.
- Retrieves matching sample resources from the server.
- Displays resource names, descriptions, and example locations.
- Provides status messages and basic error handling.
- Includes responsive styling for smaller screens.

## Project Files
- `server.js` — Express server and API endpoints.
- `resourceModule.js` — Sample data and category filtering.
- `package.json` — Project configuration and dependencies.
- `public/index.html` — Webpage structure.
- `public/app.js` — Interactive website functionality.
- `public/styles.css` — Website styling.
- `public/favicon.svg` — Website icon.

## How to Run Locally
1. Install Node.js and npm on a compatible computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `npm install` to install the dependencies.
5. Run `npm start` to start the server.
6. Open `http://localhost:5000` in your browser.

## Future Improvements
